# Biblical Leadership Match

Biblical Leadership Match (BLM) is a lightweight web experience for exploring leadership themes and matching ideas against a defined set of principles.

## Project focus

- Present leadership concepts in a clear, accessible interface
- Support simple browser-based interaction
- Keep the experience easy to run and share as a static web project

## Features

- Quiz-style matching with trait scoring
- English and Spanish interface
- Share, copy, or email your result (opens your mail app via mailto)
- Saved progress and last result in the browser

## Status

This is a public exploratory project and portfolio example.

## Run locally

Open `index.html` in a browser, or serve the repository with any local static web server.
